## 🚀 Overview

**NextJs JewelryApp** is a modern front-end application built with **Next.js** and **TypeScript** for a jewelry catalog.
It allows users to browse jewelry items, view details, and navigate a visually appealing catalog.

---

## 🎯 Features

* Display a **catalog of jewelry** with images, prices, and descriptions
* **Responsive design** for desktop and mobile
* **Smooth navigation** between pages
* SEO-friendly with **Next.js SSR**
* Easy to extend with new categories or products

---

## 🛠️ Tech Stack

* **Frontend:** Next.js, React, TypeScript
* **Styling:** CSS Modules / Tailwind / SCSS
* **Bundler & Build:** Webpack / Vercel deployment ready

## ⚡ Getting Started

1. Clone the repository:

```bash
git clone https://github.com/julianabetancurb/NextJs-JewelryApp.git
cd NextJs-JewelryApp
```

2. Install dependencies:

```bash
npm install
# or
yarn install
```

3. Run the development server:

```bash
npm run dev
# or
yarn dev
```

4. Open [http://localhost:3000](http://localhost:3000) to see the app in your browser.

---

## 📦 Build for Production

```bash
npm run build
npm start
```

This will build the optimized version and run it locally.
